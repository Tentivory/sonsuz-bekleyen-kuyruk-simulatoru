# Sonsuz Bekleyen Kuyruk Simülatörü

## Bu Nedir?

Bu, insanlık tarihinin en önemli bilimsel başarısıdır. Sonsuz bekleyen bir kuyruk simülasyonu. Kuyrukta durmak bir sanattır, biz ise bu sanatın Picasso'suyuz. Bu yazılım, evrenin entropisini ölçmek için tasarlanmıştır. Ciddi. Çok ciddi.

### Nasıl Çalışır?

1. Kişileri kuyruğa ekler.
2. Hiçbirini çıkarmaz.
3. Rastgele şikayetler üretir.
4. Sonsuza kadar devam eder.

Bu, gerçek hayatın en doğru simülasyonudur. Bankada, hastanede, devlet dairesinde yaşadığınız o his. Ama dijital ve daha da umutsuz.

## Kurulum

```bash
python kuyruk_simulatoru.py
```

Python 3.x yeterlidir. Bağımlılık yoktur çünkü ilerleme de yoktur.

## Katkıda Bulunma

Katkıda bulunmayın. Kuyruk zaten yeterince uzun. Sizin de sıranız gelmez.
